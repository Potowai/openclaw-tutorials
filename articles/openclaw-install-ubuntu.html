How to Install OpenClaw on Ubuntu in 10 Minutes

📅 March 2026 ⏱ 10 min read ✍️ OpenClaw Tutorials Team

This guide gets you from a fresh Ubuntu server or desktop to a fully running OpenClaw agent in 10 minutes. No Linux expertise required — just a terminal and the willingness to follow steps. We'll cover Ubuntu 22.04 LTS and 24.04 LTS, both on physical hardware and VPS.

Prerequisites

Before you start, make sure you have:

  • Ubuntu 22.04 or 24.04 (desktop or server edition)
  • 2 GB RAM minimum (4 GB recommended for comfortable use)
  • 10 GB free disk space
  • sudo access on the machine
  • An API key from OpenAI, Anthropic, or a compatible provider (or Ollama for fully local)

Step 1 — Update Your System

First things first — make sure your system packages are up to date. Open your terminal and run: 

sudo apt update && sudo apt upgrade -y

This takes 1-3 minutes on a fresh install. Don't skip it — outdated dependencies are a common source of installation errors.

Step 2 — Install Required Dependencies

OpenClaw needs Python 3.10+ and a few system packages. Install them with: 

sudo apt install -y python3 python3-pip python3-venv git curl wget

Python comes pre-installed on Ubuntu desktop, but the server edition sometimes doesn't include it. The above command covers all cases.

Step 3 — Clone the OpenClaw Repository

Head to the official OpenClaw GitHub repository and clone it to your machine. We'll use the standard location: 

git clone https://github.com/openclaw/openclaw.git ~/openclaw

If you don't have git installed, run sudo apt install git first. Once cloned, navigate into the directory: 

cd ~/openclaw

Step 4 — Set Up a Python Virtual Environment

It's best practice to isolate OpenClaw's Python environment from your system Python. Create and activate a virtual environment: 

python3 -m venv venv
source venv/bin/activate

You'll know the venv is active when you see (venv) at the start of your terminal prompt.

Step 5 — Install OpenClaw

OpenClaw provides an official installer script that handles most of the setup. Run it: 

pip install openclaw-agent

Or, if you cloned the repo directly: 

pip install -e .

The install process installs all required Python dependencies. This takes 2-4 minutes depending on your internet speed.

Step 6 — Configure Your API Keys

OpenClaw needs at least one LLM provider to function. Create your configuration file: 

openclaw init

This interactive command asks for your preferred provider, API key, and default model. The configuration is saved to ~/.openclaw/config.yaml. You can edit this file directly at any time.

For local models only (no API key needed), install Ollama first: 

curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.2

Then select "Ollama" as your provider during openclaw init.

Step 7 — Start OpenClaw for the First Time

With configuration done, start the agent: 

openclaw run

On first run, OpenClaw will download any required model files (if using a local provider), initialize its memory system, and present you with a prompt. Type a message and press Enter — you've just started your first conversation.

"The first question most beginners ask: 'What should I say to it?' Try: 'What can you help me with today, and what do you need access to in order to help me effectively?'" — our recommended first message.

Step 8 — Run OpenClaw as a Background Service (Optional but Recommended)

Running openclaw run in your terminal works, but the agent stops when you close the terminal. For a persistent agent that runs all the time, set it up as a systemd service: 

sudo nano /etc/systemd/system/openclaw.service

Paste the following (adjust paths as needed): 

[Unit]
Description=OpenClaw AI Agent
After=network.target

[Service]
Type=simple
User=YOUR_USERNAME
WorkingDirectory=/home/YOUR_USERNAME/openclaw
ExecStart=/home/YOUR_USERNAME/openclaw/venv/bin/openclaw run
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

Enable and start the service: 

sudo systemctl daemon-reload
sudo systemctl enable openclaw
sudo systemctl start openclaw

Check status with: sudo systemctl status openclaw

Step 9 — Connect a Messaging Platform (Highly Recommended)

The real power of OpenClaw comes alive when you can message it from your phone. The Telegram integration takes about 5 minutes:

  1. Create a bot via @BotFather on Telegram — save the token it gives you.
  2. Add the Telegram skill to your OpenClaw instance: openclaw skill install telegram
  3. Set your bot token: openclaw config set skills.telegram.bot_token YOUR_TOKEN
  4. Restart OpenClaw: sudo systemctl restart openclaw
  5. Open Telegram, find your bot, and send it any message — you should get a response.

Troubleshooting Common Issues

Permission denied on first run: Make sure your Python venv is activated. Run source ~/openclaw/venv/bin/activate before any pip install or openclaw commands.

API key rejected: Double-check for extra spaces in your config file. API keys are exact — a trailing space will break authentication.

Port already in use: If you're on a VPS with other services, openclaw run may fail on the default port. Set a custom port: openclaw run --port 8080
